# 修复交接报告（模板）

> 同一问题自动尝试达 3 次上限时，由 `pav fix` 自动生成到 `<项目>/.pav/交接报告.md`。

## 必含字段
1. **问题描述**：编码 / 文件:行 / 症状
2. **尝试记录**：每次尝试的时间、OK/FAIL、具体动作与结果
3. **卡点分析**：为什么自动修复没有成功
4. **建议动作**：交给人的具体下一步（不是泛泛的"请人工检查"）

## 页脚固定声明
> 本工具在达到尝试上限后停止，不做无限循环，也不静默放弃。

## 交接后状态
- 该问题退出自动修复循环（attempts.json 中标记）；
- 人工修复后重跑 `pav verify`，用回归证据确认修复生效。
